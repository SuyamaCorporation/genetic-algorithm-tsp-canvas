# 遺伝的アルゴリズム TSP 巡回セールスマン Canvas 可視化

遺伝的アルゴリズムで巡回セールスマン問題を解く過程をリアルタイムCanvasアニメーションで可視化。

## 特徴
- 都市数選択（10/15/20/25都市）とGAパラメータの調整
- 交叉方式（順序交叉OX/部分対応交叉PMX）の切り替え
- 選択方式（トーナメント/ルーレット）の切り替え
- 最良ルートのリアルタイムCanvas描画（グロー効果付き）
- 世代別最良/平均距離の折れ線グラフ、停滞世代数の表示

## 技術メモ
- 純JavaScriptでGA（選択・交叉・突然変異・エリート保存）を実装
- setTimeout + requestAnimationFrameで3世代/フレームを実行
- OX（Order Crossover）でルートの順序性を保持した交叉
- Fisher-Yates シャッフルで初期集団を生成
